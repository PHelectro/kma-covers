# КМА (@esportsmedicine): как готовить и публиковать пост

Этот файл читает каждый запуск автопостинга. Всё, что здесь написано, это правила владельца канала.

## Канал
- Telegram-канал КМА, t.me/esportsmedicine (chat_id `@esportsmedicine`). Тема: игры и киберспорт.
- Аудитория русскоязычная и игровая: Spirit, NAVI, BetBoom, donk, CS2, Dota 2, LoL, громкие релизы, раздачи, ностальгия.
- Публикует бот @KMA_SMM_bot через коннектор AnythingMCP «Telegram Bot API» (`telegram_bot_send_photo`).

## Расписание
- Около 10:50 мск: **новость игр** (релизы, анонсы, обновления, раздачи, коллаборации, необычные новости).
- Около 20:10 мск: **киберспорт** (итоги матчей и турниров, сенсации, трансферы, расписание важных матчей).

## Выбор новости
- Только **свежее**: событие за последние 24 часа (максимум 36). Устаревшее не брать.
- Не повторять то, что уже было: смотри `posted.md` (последние 30 строк) и не бери ту же тему.
- Сначала один поиск в широком смысле, потом проверка фактов **минимум по двум источникам**. Счёт, даты, цифры сверять обязательно.
- Слухи можно, но с пометкой «по данным инсайдера…, официально не подтверждено».
- Если по киберспорту турнир ещё идёт, точный счёт сегодняшних матчей берём только из надёжного источника (HLTV, Liquipedia, официальный сайт). Нет подтверждения — не пишем счёт.

## Текст поста (подпись к фото)
- Длина подписи до **1000 символов** (у бота лимит 1024).
- Формат: `parse_mode` = `HTML`.
- Первая строка: эмодзи + **жирный заголовок** (`<b>…</b>`), цепляющий, не кликбейт.
- Дальше 2–3 коротких абзаца: что случилось, почему это интересно, ключевые цифры.
- В конце вопрос подписчикам с голосованием реакциями, например:
  `🔥 - да` / `❤️ - нет`.
- **Только короткие дефисы «-», никаких длинных тире «—».**
- Последняя строка всегда:
  `📹<a href="https://youtube.com/@esportsmedicine?si=HDDMUdWQ5HCY5pYn"><b>YouTube</b></a> <b>|</b> 💬<a href="https://vk.cc/ccoXXI"><b>ВК</b></a>`
- Без ссылок на букмекеров, без ставок и коэффициентов как призыва. Без чужих цитат длиннее одной фразы.

## Картинка
- Только **статичная картинка** (без видео и анимации).
- Вертикальная **1080×1350 (4:5)** с логотипом КМА. Рисуется скриптом:
  `python3 tools/render_cover.py spec.json covers/ГГГГ-ММ-ДД-slug.jpg`
- `accent`: `games` (жёлтый) для игр, `esports` (бирюзовый) для киберспорта, `giveaway` (оранжевый) для раздач.
- Заголовок на обложке короткий (2–3 строки), отличается от заголовка поста. Большая цифра (`big`) — главный факт новости.
- Для матчей используй `layout: "score"` (команды, счёт, карты, плашка со следующим матчем).
- Не вставлять фото людей, логотипы команд и арт из игр, только наш дизайн.
- После рендера **открыть картинку и проверить глазами**: текст не вылезает, нет опечаток.

## Публикация
1. Сохранить обложку в `covers/`, `spec.json` в `specs/` (то же имя), добавить строку в `posted.md`:
   `- ГГГГ-ММ-ДД ЧЧ:ММ | игры/киберспорт | тема | источник`
2. Коммит от имени `Claude <noreply@anthropic.com>`, `git push` в `main`.
3. Ссылка на картинку: `https://raw.githubusercontent.com/PHelectro/kma-covers/main/covers/<файл>.jpg`
   Перед отправкой проверить, что ссылка отдаёт HTTP 200.
4. `telegram_bot_send_photo`: `chat_id` = `@esportsmedicine`, `photo` = ссылка, `caption` = текст, `parse_mode` = `HTML`.
5. Если отправка с ошибкой: исправить и повторить один раз. Не отправлять дубль, если первая попытка могла пройти.
